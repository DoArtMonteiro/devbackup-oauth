Privacy policy

Effective 3 November 2026.

DevBackup is a personal backup tool used by one person, its owner, on their own Windows PC. This policy describes what the app does with Google account access and with the data it backs up.

Who is responsible

DevBackup is written and run by Duarte Monteiro for personal use. Contact details are at the end of this page.

Google account access

  • DevBackup uses rclone to talk to the Google Drive API through DevBackup's own Google OAuth client.
  • It requests one permission: https://www.googleapis.com/auth/drive.file. This lets it create files in Google Drive and read, change or delete only the files it created. It cannot see or open other files in the account.
  • It does not request access to Gmail, contacts, calendar, profile details or any other Google service.
  • After the owner signs in, Google issues an OAuth token. The token is stored in a configuration file on the owner's PC that only the owner's Windows account and the operating system can read. It is sent only to Google, when the app calls the Google Drive API.
  • The owner can remove DevBackup's access at any time at myaccount.google.com/permissions.

What data is processed

DevBackup reads files on the owner's own PC: source code, Git repositories, configuration files, local databases and work notes. These may contain the owner's personal data. DevBackup does not set out to process data about anyone else; such data is present only where it is already inside the owner's own files.

Encryption

  • Backups are stored with restic. restic encrypts file contents, file names and metadata on the PC before upload, with AES-256 and a message authentication code, so Google Drive holds only encrypted data.
  • The owner holds the encryption password. It is not stored in Google Drive, and the app never sends it to any service.

Where data is stored

  • Encrypted backup data is stored only in the owner's own Google Drive account, under Google's terms and privacy policy.
  • There is no DevBackup server, database or website backend. This website is static and collects nothing.

Sharing, selling and advertising

DevBackup does not sell, share or transfer data to anyone. It does not use data for advertising, profiling or training AI or machine-learning models. It collects no analytics, telemetry or usage statistics.

Google API Services User Data Policy

DevBackup's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

  • Backups keep 24 hourly, 14 daily and 8 weekly snapshots. Older snapshots are removed automatically.
  • The owner can delete all backup data at any time by deleting the backup folder in Google Drive, and can revoke the app's access as described above.

Changes

If the way DevBackup handles data changes, this page will be updated with a new effective date. The page's history is public in the repository.

Contact

Open an issue in the devbackup-oauth repository, or contact the owner through the GitHub profile.
