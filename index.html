DevBackup

DevBackup is a personal backup tool. It copies one developer's Windows workstation to that developer's own Google Drive account, encrypted, once an hour. It is not a product or a service, and it has one user: its owner.

What it does

  • Every hour, a scheduled task on the owner's PC collects the development folders: source code, Git repositories (including uncommitted and unpushed work), configuration, and consistent copies of local SQLite databases.
  • It stores them with restic, an open-source backup program. restic encrypts every file on the PC before upload, and after the first run it uploads only data that changed.
  • It uploads the encrypted data to the owner's Google Drive with rclone, an open-source file transfer program.
  • It keeps 24 hourly, 14 daily and 8 weekly snapshots, checks the repository daily, and test-restores a sample of files weekly.

Why it signs in to Google

rclone needs permission to write the encrypted backup files to Google Drive. DevBackup uses its own Google OAuth client for this, so its API requests have their own quota. When the owner signs in, Google asks whether DevBackup may see, edit, create and delete only the specific Google Drive files used with this app (the drive.file permission). With that permission it cannot see or open any other file in the account.

What it does not do

  • There is no DevBackup server. Data goes from the owner's PC straight to Google Drive.
  • It collects no analytics or telemetry and shares nothing with third parties.
  • It is not offered to other people. Nobody else can use it to back up their data.

How data is handled is described in the privacy policy.

Contact

Questions about this app: open an issue in the devbackup-oauth repository, or contact the owner through the GitHub profile.
